# Sleeper Helper

Analyse-Tool für Fantasy-Football-Ligen auf [Sleeper](https://sleeper.com): Coaching-Effizienz, All-Play, Glücks-Index, Draft-Noten, Startelf-Check und Waiver-Empfehlungen – berechnet mit dem Scoring und den Kader-Slots der eigenen Liga.

**Öffnen:** https://labrwn.github.io/sleeper-helper/

Direkt mit einer Liga starten: `https://labrwn.github.io/sleeper-helper/?league=DEINE_LEAGUE_ID`

- Läuft komplett im Browser, Daten kommen live von der öffentlichen Sleeper-API.
- Erkennt Handys automatisch und zeigt dann eine eigene Handy-Ansicht.
- Kein Login: Liga laden, eigenes Team wählen, fertig.
